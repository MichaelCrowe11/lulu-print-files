# lulu-print-files

A holding place for print-ready book PDFs, attached to a GitHub release so the Lulu Print API could fetch them by URL; the repository itself has no code.

## Status

archived

One commit, dated 2026-04-15 ("init"), holding a one-line README. Tags `v1.0`, `v2.0`, and `v3.0` all point at that same commit. Only `v3.0` has a GitHub release ("Print-Ready PDFs v3.0", published 2026-04-16). Nothing has changed since. The repository is kept for reference.

## Install and first run

Not maintained. No supported install path. There is nothing to install.

## What runs today

Nothing is maintained. The `v3.0` release still carries six PDF assets (checked 2026-09-10):

- `Vol1-Interior-6x9.pdf` (57 MB), `Vol1-Cover-Paperback.pdf`, `Vol1-Cover-Hardback.pdf`
- `Vol2-Interior-6x9.pdf` (55 MB), `Vol2-Cover-Paperback.pdf`, `Vol2-Cover-Hardback.pdf`

These are two volumes of a book, interior at 6 by 9 inches with paperback and hardback covers. The PDFs live only in the release, not in git.

## Limits

This is file hosting, not software. It does not talk to Lulu, does not validate PDFs, and does not track print jobs. The PDFs are not versioned in git, so a deleted release loses them. Do not treat the release as the source of truth for the books; the source files live elsewhere.
